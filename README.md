# Silver Planner ✦

Modern travel planner berbasis web, dibuat dengan vanilla HTML/CSS/JavaScript dan siap dipasang di GitHub Pages.

## Fitur
- Dashboard travel
- Search destinasi
- Filter vibe & sorting budget
- Product/destination detail
- Wishlist
- Trip cart
- Checkout + voucher demo `SILVER10`
- Dark mode
- Sound feedback
- LocalStorage
- Budget chart
- Checklist perjalanan
- Export trip menjadi JSON
- Responsive & fluid mobile layout
- WhatsApp-ready button
- Tanpa build step dan tanpa framework berat

## Struktur
- `index.html`
- `style.css`
- `app.js`
- `data.json`
- `README.md`

## GitHub Pages
Upload seluruh file ke repository → Settings → Pages → Deploy from branch → pilih branch utama dan folder `/root` → Save.

### WhatsApp
Fitur tombol WhatsApp sudah disiapkan. Untuk membuatnya benar-benar membuka chat, ubah `WHATSAPP_NUMBER` di `app.js` sesuai nomor bisnis yang ingin digunakan.
